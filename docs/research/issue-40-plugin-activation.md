- [OpenCode databasePath](https://github.com/anomalyco/opencode/blob/v2/packages/cli/src/database-path.ts): relative `OPENCODE_DB` resolves under OpenCode's data folder; `:memory:` stays special. OpenCode's own custom-channel service registration/config filenames are separate from that ticket's selection rule; the launcher performs no service migration or write.
- [Local-directory resolution](https://github.com/anomalyco/opencode/blob/v2/packages/plugin/src/host.ts): filesystem directories use conventional `server`/`index` files; package exports are used for named installed packages. The workspace therefore has a one-line `server.ts` forwarding entry, covered by the source gate inventories, while its package export still points into `src/`. The release emits its existing conventional `server.js` at the package root.
